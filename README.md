# capstone-explore

| Topic | Pros | Cons | Gap |
| --------------- | --------------- | --------------- | --------------- |
| Structure-Aware Unit Test Generator | Familiar domain | Having to prove clear advantages compared to normal coding agents | Current LLM-based approaches focus solely on the code (like referenced variables), neglecting task-specific contexts |
| Large-scaled log analysis | An up-to-date problem and there doesn't seem to be a definite/good existing solution | Solve the problem from structured and unstructured logs while keeping the performance stable is difficult | Scalability and risk of event's order/relation loss |
| Prompt injection detection | Clear needs, not saturated topic | Team might lack experience on Vietnamese prompt attack technique | Weak bilingual performance |
| RAG poisoning detection | Attacks are measurable | Need an existing system | Systems on this topic is still not yet matured |
| Version-aware Vietnamese legal assistant | Relevant in Vietnam | Require ability to process legal data | Usually skips the dates and and process of changes in laws |
