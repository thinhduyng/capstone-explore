IEEE XPLORE
------------

1. Repository-Aware Code Assistant
   Product type: Developer chatbot / IDE assistant
   What it does: Answers questions about an entire codebase using functions,
   dependencies, tests, and documentation.
   Input: A repository and a developer question.
   Expected output: A grounded explanation, relevant files/functions, and source
   references.
   Comment: old paper (Feb 2025)

2. RAG-Based Test Case Generator
   Product type: Software automation tool
   What it does: Retrieves requirements and related source code to generate relevant
   test cases.
   Input: A requirement, issue, or target function.
   Expected output: Executable unit tests with links to supporting requirements and
   code.
   Comment: maybe? but test cases generation might need further learnings

3. Secure RAG Attack Detector
   Product type: Security testing dashboard
   What it does: Tests whether poisoned documents or indirect prompt injections can
   manipulate a RAG system.
   Input: A RAG corpus, test questions, and attack documents.
   Expected output: A risk score, detected malicious passages, affected answers, and
   an evaluation report.
   Comment: has to based off a working LLM system?

4. Course-Grounded Programming Assistant
   Product type: Educational chatbot
   What it does: Answers course questions and provides programming hints based only
   on authorized course materials.
   Input: Lectures, labs, assignments, and a student's question or code.
   Expected output: A cited explanation, relevant lesson, and guided hint.
   Comment: old paper

   Product type: Design automation tool

   Comment: same as 2

4. Self-Correcting Log Analysis System
   Product type: Developer automation tool / monitoring dashboard
   What it does: Parses application logs, discovers event templates, and corrects
   uncertain parsing results.
   Input: Raw system or application logs.
   Expected output: Structured log events, templates, anomalies, and confidence
   scores.
   Comment: good
